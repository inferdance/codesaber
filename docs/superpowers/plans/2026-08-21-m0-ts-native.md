# M0 实施计划:TS-Native Engine Skeleton

> 日期:2026-08-21。上游 spec:`docs/superpowers/specs/2026-08-21-codesaber-ts-native-design.md`。
> 目标:TS monorepo + Effect 骨架 + 核心安全不变量 + CLI headless + 测试。

## Definition of Done

1. `pnpm build` 在干净 checkout 上成功(零 TS 错误)
2. `pnpm test` 全部通过(含从 Rust 版继承的安全边界断言)
3. `saber exec -p "make greet more enthusiastic and verify"` 在真实仓库完成 read→edit→bash(test)→final
4. 安全不变量全部有测试:路径逃逸拒绝/秘钥读取拒绝/坏参数拒绝/WAL intent 落盘
5. CI(GitHub Actions: ubuntu lint+test, macOS sandbox test)绿

## 任务分解

### T1: Monorepo 骨架(0.5d)
- pnpm workspaces + tsconfig(strict,ESM,`.js` import 后缀)
- packages/{core,ai,server,cli,sandbox} 目录
- vitest 配置(所有包共享)
- ESLint + Prettier
- GitHub Actions CI

### T2: Zod Schemas + Effect Layer(0.5d)
- `core/src/schema/tools.ts`:六工具参数 schema(read/write/edit/bash/grep/glob)
- `core/src/schema/events.ts`:引擎事件 schema
- `core/src/layer/`:ProviderLayer/ToolRegistryLayer/PathPolicyLayer/SessionLayer
- 验收:schema 校验测试(好参数通过/坏参数拒绝/边界值)

### T3: 路径策略 + 编辑工具(1d)
- `core/src/policy/`:统一路径策略(`path.relative` 判边界,非 startsWith)
- `core/src/edit/`:编辑容错(fast-diff + 六级策略)
- 安全测试:前缀绕过拒绝/symlink 逃逸拒绝/秘钥后缀拒绝/多行精确/Unicode
- 验收:Rust 版 path_policy 6 个测试 + edit 9 个测试全部继承

### T4: bash + 搜索工具(1d)
- bash:execa(超时/env 清洗/进程组)+ 流式输出截断
- grep:ripgrep JSON 输出模式(不走 shell 拼接)
- glob:fast-glob + 手动加载 .gitignore 到 ignore 数组
- 所有搜索工具走 PathPolicy(checkRead)
- 验收:bash 超时杀进程/env 无密钥/秘钥文件不可搜索

### T5: Session WAL + Engine Loop(1.5d)
- SessionLog:JSONL append-only,intent fsync
- Engine:turn/step loop,三防线(length/doom-loop/WAL),多工具 Map 累积
- 恢复:intent-无-result 标记,撕裂尾截断
- 验收:E2E(mock provider 驱动 read→edit→bash→final)+ 故障矩阵(length/doom/steer/crash)

### T6: CLI + AI Provider(1d)
- AI:SSE 手写(~80 行)+ OpenAI 兼容 + Anthropic + retry
- CLI:saber exec -p --json --model --timeout(saber doctor)
- 验收:saber exec 在真实仓库跑通;退出码 0/1/124 正确

### T7: Seatbelt 沙箱(0.5d, macOS-only)
- Seatbelt profile 构建器(workspace-write-lite)
- 集成到 execa 调用链(sandbox-exec 包装)
- macOS CI job 跑沙箱测试
- 验收:cwd 外写拒绝/网络拒绝/秘钥拒绝/PTY 通过/pnpm --filter @saber/sandbox --fail-if-no-match test 通过

### T8: 文档收尾(0.5d)
- README 更新(安装命令 npm/bunx)
- AGENTS.md 更新(TS 工程规范)
- Harbor adapter 脚手架
- 基线评测文档

## 估时

约 6.5 人日(T1-T8 串行);T2/T3 并行,T4/T5 并行,压缩后 ~4 天。
