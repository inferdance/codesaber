> 日期:2026-08-21。上游 spec:`docs/superpowers/specs/2026-08-21-codesaber-ts-native-design.md`。

## Definition of Done

1. `pnpm build` 在干净 checkout 上成功(零 TS 错误)
2. `pnpm test` 全部通过(含从 Rust 版继承的安全边界断言)
3. `saber exec -p "make greet more enthusiastic and verify"` 在真实仓库完成 read→edit→bash(test)→final
4. 安全不变量全部有测试:路径逃逸拒绝/秘钥读取拒绝/坏参数拒绝/WAL intent 落盘
5. CI(GitHub Actions: ubuntu lint+test, macOS sandbox test)绿

## Amendments(2026-08-24,M0 完成时记录的实现偏差)

实施过程中的有意偏差,以本节为准(原任务描述保留作历史):

1. **Effect Layer 未采用(T2)**:实现为普通类 + 依赖注入构造参数。Effect 在 60% 里程碑后引入只会增加概念负担,TypeScript strict + Zod 已覆盖运行时校验目标。若 M1 需要 Layer 测试隔离再评估。
2. **edit 五级容错,纯手写(T3)**:exact → escape-normalized → trailing-ws → indent-flexible → whitespace-normalized。原规格的 fast-diff + 六级未采用:fast-diff 服务于偏移量式编辑模型,而本实现的锚点式模型在 indent-flexible 层需要"逐行转移文件真实缩进"语义(fast-diff 给不出)。每一级带结构护栏(行数一致、歧义必报)。原"行级/模糊"两级中,行级子集匹配(block-anchor)未实现——真实模型输出很少需要,留待有失败案例再补。
3. **grep 用 rg JSON 模式(T4)**:如规格要求,`--json` 事件流结构化解析,每条匹配按真实路径过 checkRead,密钥匹配计数隐藏。JS 兜底 walker 同样逐文件过 checkRead(密钥文件根本不读入)。
4. **glob 纯手写(T4)**:零依赖 globToRegExp(`**`/`*`/`?`/`{a,b}`)+ walker,根 .gitignore 感知。fast-glob 未引入——需求已被 25 个用例覆盖,少一个依赖。
5. **bash 进程组击杀(T4)**:execa 9.x 无 `killDescendants` 选项;实现为 detached(独立进程组)+ 超时对整组 SIGKILL,孙进程不残留。输出为缓冲后中部截断(60/30),非流式——流式截断留 M2(maxBuffer 10MB 封顶内存)。
6. **read 增加 offset/limit 分页(T4 后追加)**:长文件按绝对行号翻页。
7. **Seatbelt 沙箱(T7)推迟至 M2**:用户决策(自用全权限场景),macOS CI 沙箱 job 一并推迟。
8. **Harbor adapter 脚手架(T8)推迟至 M2**:评测优先级让位于 M1 三前端。
9. **追加的规格外守卫**:edit 前必须 read(新鲜度)、write 也注册 readFiles;测试类型检查链(`tsconfig.tests.json`,补上 vitest 不查类型的缺口)。
