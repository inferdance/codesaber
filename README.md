## 🗡️ What is CodeSaber?

CodeSaber is an AI coding agent that treats your codebase like a battlefield —
it **plans** the attack, **strikes** with surgical edits, and **sheathes**
when the tests pass.

No endless chatting. Draw the blade, cut the problem.

## ✨ Philosophy

| Command | Meaning |
|---------|---------|
| **Draw** (`saber draw`) | Understand the mission — read the codebase, form a plan |
| **Strike** (`saber strike`) | Execute — write code, run tests, fix failures |
| **Sheathe** (`saber sheathe`) | Ship — clean diffs, ready for review |

Inspired by the lightsaber: precision over brute force,
one clean cut over a thousand scattered edits.
